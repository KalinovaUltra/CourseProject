# CourseProject
<br>Система для управления учебными документами (заявления, справки, т.д.).  
<br>Проект реализован на **HTML**, **CSS**, **JavaScript** с использованием **Mock API** для имитации бэкенда.

<br>Перейдите в папку с проектом.
<br>Проект будет запускается через командную строку с помощью команды npm start
<br>Ctrl + C для выхода
