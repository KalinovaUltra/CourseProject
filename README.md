Система документооборота для студентов представляет собой:
        1. Header с кнопкой для перехода в личный кабинет (в рамках курсового проекта интерфейс и функционал личного кабинета реализован не будет).
        2. Контейнер формы с выпадающим списком для выбора категории документа. Возможность оставить комментарий.
        3. Загрузка формы документа после выбора категории, заполнение формы пользователем. Форма документа не отображается, если пользователь ничего не выбрал.
        4. Кнопка отправить в деканат и кнопка сохранить документ на компьютер. После нажатия на одну из кнопок пользователю высвечивается уведомление документ отправлен/документ сохранен/заполните все поля и т.д.
