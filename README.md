# CourseProject
Система для управления учебными документами (заявления, справки, т.д.).  
Проект реализован на **HTML**, **CSS**, **JavaScript** с использованием **Mock API** для имитации бэкенда.

Перейдите в папку с проектом.
Проект будет запускается через командную строку с помощью команды npm start
Ctrl + C для выхода
